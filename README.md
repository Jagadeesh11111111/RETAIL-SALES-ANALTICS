# Retail Sales Analytics Project

## Project Overview
An end-to-end Retail Sales Analytics project designed to analyze sales performance, product performance, customer behavior, regional sales, and monthly trends.

## Tools Used
- Microsoft Excel — Data cleaning, PivotTables, KPI cards, interactive dashboard and slicers
- SQL Server — Data validation, aggregation, business analysis, CTEs and window functions
- Microsoft Power BI — Interactive dashboard, KPIs, DAX measures, filters and visualizations

## Project Objectives
1. Analyze overall sales performance.
2. Identify top-performing products and categories.
3. Compare sales across regions.
4. Analyze monthly sales trends.
5. Understand customer purchase behavior.
6. Calculate average order value.
7. Identify business opportunities using data.

## Project Files
- `Excel/` — Excel workbook and dashboard
- `SQL/` — SQL queries and analysis
- `PowerBI/` — Power BI report
- `Screenshots/` — Dashboard previews

## Key Business Questions
- Which category generates the highest revenue?
- Which are the top 10 products by sales?
- Which region contributes the most sales?
- How do sales change month over month?
- Which customers contribute the most revenue?
